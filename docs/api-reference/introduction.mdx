|--------|-------------|

| `procesar_docs.py` | Pipeline ETL de documentos |
| `utils.py` | Funciones auxiliares |

## Endpoints Conceptuales

Aunque es una aplicación Streamlit (no REST), podemos conceptualizar las operaciones:

```
POST /query
  Input: { "question": str, "model": str, "k": int }
  Output: { "answer": str, "context": str, "time": float }

POST /process
  Input: { "documents": List[Path] }
  Output: { "chunks_created": int, "status": str }
```
