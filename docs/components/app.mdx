## Template del Prompt

El sistema utiliza un prompt estructurado con **4 niveles de prioridad**:

<Steps>
  <Step title="PRIORIDAD 1: Contexto INAOE">
    El `CONTEXTO` extraído de los documentos internos es la verdad fundamental.
  </Step>
  <Step title="PRIORIDAD 2: Conocimiento General">
    Conocimiento interno del modelo sobre ciencia y tecnología.
  </Step>
  <Step title="PRIORIDAD 3: Fuentes Verificables">
    Principios y datos de fuentes académicas universalmente aceptadas.
  </Step>
  <Step title="PRIORIDAD 4: Búsqueda Web">
    Si no hay información en la base de datos, se busca en internet.
  </Step>
</Steps>

### Formato de Salida Obligatorio

```python
@st.cache_resource
def cargar_base_datos():
    """Carga la base de datos vectorial FAISS de forma segura."""
    device = 'cuda' if torch.cuda.is_available() else 'cpu'
    embeddings = HuggingFaceEmbeddings(
        model_name="all-MiniLM-L6-v2",
        model_kwargs={'device': device},
        cache_folder=str(RUTA_PROYECTO / "models")
    )
    return FAISS.load_local(str(RUTA_DB), embeddings)
```

<Note>

### `get_llm()` - Fábrica de LLMs

<ParamField path="modelo" type="str" required>
  Nombre del modelo (ej: "gemini-1.5-flash")
</ParamField>
<ParamField path="temperature" type="float" required>
  Creatividad del modelo (0.0 - 1.0)
</ParamField>
<ParamField path="timeout" type="int" required>
  Timeout en segundos (30 - 300)
</ParamField>

```python
def get_llm(modelo, temperature, timeout):
    """Fábrica que devuelve una instancia del LLM seleccionado."""
    config = MODEL_CONFIG.get(modelo, {})
    provider = config.get("provider")

    if provider == "google":
        return ChatGoogleGenerativeAI(
            model=modelo.split('/')[-1], 
            api_key=st.secrets["GOOGLE_API_KEY"]
        )
    elif provider == "ollama":
        return ChatOllama(model=modelo, temperature=temperature)
    elif provider == "groq":
        return ChatGroq(api_key=st.secrets["GROQ_API_KEY"])
    elif provider == "together":
        return Together(model=modelo, api_key=st.secrets["TOGETHER_API_KEY"])
```

### `buscar_en_internet()`

<ParamField path="consulta" type="str" required>
  Texto de búsqueda
</ParamField>
<ParamField path="max_resultados" type="int" default="5">
  Número máximo de resultados
</ParamField>

```python
def buscar_en_internet(consulta: str, max_resultados: int = 5) -> List[str]:
    """Fallback a DuckDuckGo cuando el contexto local es insuficiente."""
    from duckduckgo_search import DDGS
    with DDGS() as ddgs:
        for item in ddgs.text(consulta, region="wt-wt", max_results=max_resultados):
            resultados.append(f"Título: {item['title']}\n...")
    return resultados
```

## Cadena RAG Principal

La función `create_rag_chain()` implementa el flujo completo:

```python
def create_rag_chain():
    def rag_invoke(question):
        # 1. Recuperar documentos relevantes
        docs = retriever.get_relevant_documents(question)
        context = format_docs(docs)
        
        # 2. Fallback a internet si contexto insuficiente
        if not context or len(context.strip()) < 50:
            resultados_web = buscar_en_internet(question)
            context = f"[Fuente: Internet]\n{contexto_web}"

            "answer": response.content
        }
    return rag_invoke
```
