## Bienvenido al Asistente INAOE 🚀

El **Asistente de Investigación INAOE** es un sistema de Generación Aumentada por Recuperación (RAG) diseñado para ayudar a los investigadores del Instituto Nacional de Astrofísica, Óptica y Electrónica a consultar y analizar documentos científicos de manera eficiente.

## Características Principales

<AccordionGroup>
  <Accordion icon="brain" title="Multi-Proveedor LLM">
    Soporte para múltiples proveedores de modelos de lenguaje:
    - **Ollama** (Local): DeepSeek R1, Mistral 7B
    - **Google** (API): Gemini 1.5 Flash, Gemini 1.5 Pro
    - **Groq** (API): LLaMA 3 8B (preparado)
    - **Together AI** (API): Preparado para activación
  </Accordion>
  <Accordion icon="microscope" title="Enriquecimiento NLP">
    Pipeline de procesamiento de documentos con:
    - **spaCy** (es_core_news_lg): NER general en español
    - **BERT Spanish NER**: Reconocimiento de entidades especializado
  </Accordion>
  <Accordion icon="database" title="Base de Datos Vectorial FAISS">
    Almacenamiento y recuperación eficiente de embeddings usando:
    - Modelo: `all-MiniLM-L6-v2`
    - Soporte GPU/CPU automático
    - Procesamiento incremental
  </Accordion>
  <Accordion icon="globe" title="Fallback Inteligente">
    Cuando el contexto local es insuficiente:
    - Búsqueda automática en DuckDuckGo
    - Integración transparente en respuestas
  </Accordion>
</AccordionGroup>

## Stack Tecnológico

| Categoría | Tecnología | Versión |
|-----------|------------|---------|
| **Frontend** | Streamlit | Latest |
| **Framework LLM** | LangChain | Latest |
| **Base Vectorial** | FAISS | CPU |
| **NLP** | spaCy + Transformers | 3.7+ |
| **Embeddings** | Sentence Transformers | all-MiniLM-L6-v2 |
| **Python** | Python | 3.9+ |
