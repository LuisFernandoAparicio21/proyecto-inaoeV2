# React App - INAOE RAG Assistant Frontend

## Descripción
Interfaz React moderna para el Asistente de Investigación INAOE.

## Requisitos
- Node.js 18+
- npm o pnpm

## Instalación
```bash
cd frontend/react-app
npm install
```

## Desarrollo
```bash
npm run dev
```

## Configuración
Crear archivo `.env` con:
```
VITE_API_URL=http://localhost:8000/api/v1
```

## Build para producción
```bash
npm run build
```

Los archivos se generan en `dist/`.

## Stack
- React 19
- TypeScript
- Tailwind CSS
- Radix UI
- Framer Motion
- Vite
